# Rime 小狼毫大易輸入法設定包

這是一套給 Windows 11 使用的 Rime／小狼毫大易輸入法設定包。若原本的大易輸入法在 Chrome 輸入時發生閃退，可改由小狼毫載入本套大易方案，避開原輸入法與 Chrome 的相容性問題，同時保留熟悉的大易碼表、選字鍵與候選順序。

> 本工具不會修改 Chrome，也不是針對 Chrome 程式本身的修補程式；它是以 Rime／小狼毫取代原本的大易輸入路徑。

## 功能特色

- 保留大易數字字根，鍵盤上方 `0`～`9` 可正常輸入字根。
- 收錄四碼、三碼、二碼速成與容錯簡碼，候選字依字典原始順序固定排列。
- 使用微軟大易習慣的五個選字鍵：`Space`、`'`、`[`、`]`、`-`。
- 關閉行內預編輯，減少游標所在文字列的視覺干擾。
- 輸入 `=` 可開啟常用標點與符號選單。
- 輸入反引號 `` ` `` 可啟動臺灣注音反查。
- 同時提供「大易四碼」與「臺灣注音」方案。

## 系統需求

- Windows 11
- 已安裝 [Rime 小狼毫](https://rime.im/)
- 目前設定檔記錄的環境為 Weasel `0.17.4`、Rime `1.13.1`

## 安裝方式

1. 先備份 `%APPDATA%\Rime` 資料夾。安裝程式會覆寫同名設定檔，且不會自動建立備份。
2. 下載本儲存庫並完整解壓縮，請勿只在壓縮檔內直接執行。
3. 雙擊 `一鍵安裝與還原大易.bat`。
4. 程式會將下列檔案複製到 `%APPDATA%\Rime`：
   - `dayi4.schema.yaml`
   - `dayi4.dict.yaml`
   - `default.custom.yaml`
   - `weasel.custom.yaml`
5. 安裝程式會嘗試執行小狼毫重新部署；若找不到部署程式，請在 Windows 右下角通知區對小狼毫圖示按右鍵，再選擇「重新部署」。
6. 使用 `Win + Space` 或 `Ctrl + Shift` 切換至小狼毫，並選擇「大易四碼」。

## 選字鍵

| 候選順位 | 按鍵 |
| --- | --- |
| 第 1 字 | `Space` |
| 第 2 字 | `'` |
| 第 3 字 | `[` |
| 第 4 字 | `]` |
| 第 5 字 | `-` |

例如輸入 `eoj` 時，候選順序會固定顯示為「可、事、哥」。

## 還原方式

最安全的方式是將安裝前備份的 `%APPDATA%\Rime` 還原，然後重新部署小狼毫。若沒有備份，請勿直接刪除可能原本就存在的同名檔案；先確認檔案是否由本工具安裝。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `一鍵安裝與還原大易.bat` | 複製設定檔並觸發小狼毫重新部署 |
| `dayi4.schema.yaml` | 大易四碼方案、選字鍵、符號與注音反查設定 |
| `dayi4.dict.yaml` | 大易固定順序完整字典 |
| `default.custom.yaml` | 啟用大易四碼與臺灣注音方案 |
| `weasel.custom.yaml` | 小狼毫外觀、橫向候選與關閉行內預編輯設定 |
| `使用說明.txt` | 原始簡要安裝說明 |

## 注意事項

- `default.custom.yaml` 與 `weasel.custom.yaml` 會覆寫使用者目錄中的同名檔案；已有自訂設定者請先備份並自行合併。
- 自動部署僅會檢查批次檔內列出的常見安裝路徑；其他版本或自訂安裝位置可能需要手動重新部署。
- 本儲存庫目前未附授權檔。公開散布或再利用前，請確認碼表與相關檔案的來源及授權。
- 若 Chrome 閃退並非由原輸入法造成，改用本設定包不一定能解決該問題。
